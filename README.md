Simple Portfolio Website

This is a simple personal portfolio website created using HTML and basic CSS. The purpose of this project is to practice basic web development skills and understand how to structure a simple website.

The website contains two main pages: Home and Contact.

Home Page

The Home page introduces the portfolio and provides basic information about the developer. It includes a simple layout with headings, text, and navigation links that allow users to move between pages.

Contact Page

The Contact page contains a basic contact form where users can enter their details such as name, email, and message. This page demonstrates how to create forms using HTML.

Technologies Used

HTML5

CSS3 (Basic Styling)

Features

Simple and clean design

Easy navigation between pages

Basic contact form

Beginner-friendly project structure

Purpose of the Project

This project was created as a beginner practice project while learning front-end web development. It helps in understanding HTML structure, linking pages, and applying basic CSS styling.
